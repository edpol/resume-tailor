# Insurance Care Direct — Project Summary
**Role:** Laravel Developer | **Dates:** 05/2019 – 10/2019
**Stack:** PHP, Laravel, Vue.js, MySQL, Docker (Vagrant/Homestead)

## Silverback — Insurance Professional Platform
- Built "Silverback," a Laravel/Vue.js application for insurance professionals
- Integrated tools for sales management, marketing, education resources, and lead management in a single dashboard
- Used Ample Admin dashboard template; customized heavily for insurance workflow
- Implemented writing numbers management: admin UI to assign and manage insurance carrier writing numbers per user, supporting multi-carrier genealogy and product family tracking
- Built user management with role-based access, search by name/email/username, and CRUD operations
- Revamped site UX, improving navigation and accessibility for agents
- Set up Vue.js within Laravel using webpack/mix build pipeline in a Vagrant-based Docker environment
