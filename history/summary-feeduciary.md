# Feeduciary.com — Project Summary
**Role:** Software Developer (Freelance) | **Dates:** 01/2018 – 12/2018
**Stack:** PHP, Laravel, MySQL, Google Maps API, ImageMagick, Postman

## Fiduciary Advisor Marketplace
- Built a Laravel-based marketplace from scratch connecting fee-only financial advisors with prospective clients
- Advisors created profiles with detailed fee structures (single rate, cumulative, fee-only models)
- Clients could search for advisors by investment amount and geography (75-mile radius) and compare fees side-by-side
- Implemented Google Maps API for location-based advisor search and display
- Used ImageMagick for advisor profile image optimization
- Built email notification system: welcome emails to new advisors, alerts to admin on new signups and client inquiries
- Implemented lead capture gate: email-gated search results with cookie/session persistence to avoid repeated prompts
- Integrated MailChimp-compatible email storage for captured leads
- Set up SSL/HTTPS, SEO basics (sitemap.xml, robots.txt), and Google Analytics
- Designed intuitive UI/UX for both advisor profile creation and client-facing search/comparison flow
- Tested and documented APIs using Postman
